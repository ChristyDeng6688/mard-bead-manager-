# MARD 221 拼豆管理网页版

这是一个本地网页应用，用于管理 MARD 221 色拼豆库存。数据保存在当前浏览器本地存储中，不需要安装，也不需要联网。

## 打开方式

直接双击 `index.html`，建议使用 Microsoft Edge、Google Chrome 或其他现代浏览器打开。

如果页面没有正常显示，可以右键 `index.html`，选择“打开方式”，使用 Edge 或 Chrome。

## 推荐使用动线

网页已经按日常使用顺序组织：

1. 先看 **使用指南**，确认操作流程和手机端保存方式。
2. 在 **仓库** 建立期初库存。
3. 在 **计算器** 按单次拼图记录用豆，色号多时使用批量导入或图纸识别。
4. 在 **拼豆里程** 查看用量、趋势、排行和成本。
5. 在 **补货清单** 检查低库存色号，再带回计算器登记增补。
6. 需要核对颜色时使用 **色卡**。

欢迎页会按这条路径排列入口，顶部标签栏顺序也已同步。每个主要页面的底部都提供“下一步”操作，切换页面时会自动回到顶部；手机端顶部标签会自动把当前页面滚进可见区域。

## 功能说明

### 仓库

- 查看 MARD 221 色的期初库存、累计变动、当前库存、预警值和状态。
- 仓库支持按 A、B、C、D、E、F、G、H、M 字母分类筛选，并在表格中显示分类标签。
- 可以直接在表格里填写每个色号的期初库存。
- 每个期初库存输入框旁边都有 `-500` 和 `+500` 快捷按钮，可以按 500 一组快速调整。
- 支持按字母分组筛选，也支持搜索色号。
- 支持自定义预警阈值，默认是 30 颗；修改后会同步更新仓库状态、补货清单和建议补充数量。
- 点击“批量导入期初”可以一次导入多个色号的期初数量。

批量导入格式，每行一条：

```text
A1 5000
A2 1200
B5,300
```

支持空格、逗号或 Tab 分隔。

### 计算器

计算器按软件方式操作：

1. 选择“拼豆用”或“后续增补”。
2. 输入日期和拼图名称 / 来源用途。
3. 搜索并选择色号。
4. 输入数量；后续增补可以点击快捷按钮，拼豆用请填精确用量。
5. 点击“确认记录”。

确认后会立即保存记录，并自动更新仓库库存。

`拼豆用`需要填写精确用量；`后续增补`支持 `+500`、`+1000`、`+2000` 和 `-500` 快捷操作。

“拼豆用”会自动扣减库存，“后续增补”会自动增加库存。

### 批量导入

一张拼图使用很多色号时，可以使用“批量导入”：

1. 从图纸软件复制色号和数量两列。
2. 在计算器页点击“批量导入”。
3. 粘贴为每行一条，例如：

```text
A1 500
A2 1200
B5 300
```

4. 选择类型、日期和拼图名称。
5. 点击“导入记录”。

后续增补如果一行只填色号，可以在导入窗口选择默认数量 `500`、`1000` 或 `2000`。拼豆用必须每行填写精确用量。

### 最近记录

- 可以查看最近保存的记录。
- 可以按“拼豆用”或“后续增补”筛选。
- 可以删除单条记录，删除后库存会自动回滚。

### 图纸识别

图纸识别已经集成在计算器页面中，不需要单独保存图片。

使用方法：

1. 在计算器页面找到“图纸识别”。
2. 上传 PNG、JPG 或 WebP 图纸。
3. 选择识别网格，或使用自动检测。
4. 点击“开始识别”。
5. 在识别结果中修改色号、数量，或添加、删除结果行。
6. 点击“带入计算器”，结果会预填到批量导入窗口。
7. 确认导入后，记录会进入拼豆用流水并扣减仓库。

图纸图片不会上传，也不会保存到应用中。

### 拼豆里程

- 支持本周、本月、近 30 天、本年和自定义时间范围。
- 日历固定在左侧长方形区域，按 7 列等宽排列。
- 有拼豆记录的日期会自动画圈，点击两个日期即可直接选择统计区间。
- 统计拼图数量、用豆数量、补充数量和成本。
- 支持设置每颗参考成本，计算用豆成本和增补成本。
- 显示用豆与增补趋势、色号使用排行和流水明细。
- “拼豆小记”包含“地球 Online 今日任务”和“金句”两个标签。
- 今日任务每天自动更换一组，包含 3 个常规任务和 1 个彩蛋任务；勾选状态保存在当前浏览器。
- 金句包含中文古典、中文现代和英文美句，英文金句附有中文释义。
- “导出 PDF 报告”会打开浏览器打印窗口，选择“另存为 PDF”即可保存；报告包含统计、排行和流水明细。
- “导出明细”会下载当前时间范围的 CSV。

### 补货清单

- 当前库存低于或等于自定义预警阈值时，色号会自动出现在补货清单。
- 显示当前库存、状态和建议补充数量。
- 点击“去增补”可以直接带到计算器，并自动填入色号和建议数量。

### 色卡

- 查看 MARD 221 色的色号、HEX 和颜色标签。
- 支持搜索色号，点击色块可以直接带到计算器。

## 数据备份

网页版的数据默认保存在当前浏览器中。

建议定期点击右上角“备份”，导出 JSON 文件保存。

备份会同时保存期初库存、流水记录和自定义预警阈值。

换电脑、换浏览器或清理浏览器数据前，请先导出备份。

需要恢复数据时，点击右上角“导入”，选择之前导出的 JSON 文件。

## 部署到 GitHub Pages

这个项目是纯静态网页，适合直接部署到 GitHub Pages。

部署后可以正常使用：

- 仓库库存
- 计算器
- 补货清单
- 色卡
- 图纸识别
- CSV 下载
- JSON 备份和恢复

完整步骤请查看：

```text
GITHUB_DEPLOY.md
```

部署时要注意：

- 把 `index.html` 等文件直接放在仓库根目录。
- 不要只上传“网页版”文件夹。
- GitHub Pages 的 Branch 选择 `main`，Folder 选择 `/ (root)`。
- 部署成功后网址类似 `https://你的用户名.github.io/仓库名/`。

数据不会上传到 GitHub，仍然保存在当前浏览器中。相同设备、相同浏览器和相同网址会继续保留数据。

如果之前一直用本地 `file://` 地址，部署后需要通过“备份”和“导入”迁移一次数据。

## 手机端使用与保存

### iPhone / iPad（iOS / iPadOS）

打开方法：

1. 把整个“网页版”文件夹保存到“文件”App，例如“我的 iPhone > 拼豆相关”。
2. 在文件 App 中点击 `index.html`，选择用 Safari 打开。
3. 如果直接打开无效，长按文件，选择“共享”，再用 Safari 打开。

保存方法：

1. 在网页里记录库存后，点击右上角“备份”。
2. 把导出的 JSON 文件保存到“文件”或 iCloud Drive。
3. 换设备时，在新设备打开网页，点击“导入”选择 JSON 备份。

注意：建议使用 Safari 或 Chrome。微信、QQ 等内置浏览器可能无法稳定保存本地数据。

### Android 手机 / 平板

打开方法：

1. 把“网页版”文件夹放到“下载”或“文档/拼豆相关”。
2. 打开系统文件管理，点击 `index.html`。
3. 选择 Chrome、Edge 或其他现代浏览器打开。

保存方法：

1. 使用网页后点击“备份”，备份文件默认会下载到浏览器下载目录。
2. 把 JSON 备份移动到 Documents 文件夹或云盘，例如 Google Drive、百度网盘。
3. 浏览器支持时，可以通过菜单“添加到主屏幕”创建快捷入口。

注意：本地文件在部分浏览器中不能添加到主屏幕。如果需要更像 App 的体验，建议后续把网页部署到静态网站。

### HarmonyOS / 华为设备

打开方法：

1. 把“网页版”文件夹保存到设备本地存储或华为云盘。
2. 在“文件管理”里点击 `index.html`，选择华为浏览器打开。
3. 如果浏览器没有直接打开，先选择“用其他应用打开”，再选浏览器。

保存方法：

1. 使用网页后点击右上角“备份”。
2. 把 JSON 备份保存到“文件管理”的文档目录，再上传到华为云盘。
3. 需要恢复时，打开网页，点击“导入”，选择之前保存的 JSON 文件。

注意：不建议把数据只保存在浏览器缓存里。换手机、清理缓存或重装浏览器前，请先导出备份。

### 所有手机通用保存规则

- 网页数据保存在当前浏览器本地，不会自动同步到其它设备。
- 换设备、换浏览器、清理缓存前，一定先导出 JSON 备份。
- 整个“网页版”文件夹要一起保存，不要只单独移动 `index.html`。
- 尽量不要修改文件夹路径，否则浏览器可能认为这是一个新的页面，原来的数据不会自动显示。
- 手机端如果发现数据无法稳定保存，优先使用“备份/导入”，并保存到系统文件或云盘。

## 注意事项

- 网页版和 Excel 数据不会自动同步。
- 网页版数据保存在浏览器本地，不会上传到服务器。
- 清空浏览器缓存或网站数据可能会导致网页版记录丢失，请定期备份。
- 手机端建议使用系统浏览器，不要用微信或 QQ 内置浏览器保存数据。
- 换设备前先导出 JSON 备份。
- 颜色值是屏幕近似参考，实物颜色会受到批次、光线和显示器影响。

## 推荐使用方式

1. 第一次打开后，先看使用指南，再到仓库页填写期初库存，或使用“批量导入期初”。
2. 每次拼图结束后，在计算器页记录用豆数量；大图使用“批量导入”或图纸识别一次导入所有颜色。
3. 在拼豆里程页查看一段时间内的拼图数量、用豆量、增补量和成本。
4. 补货时查看补货清单，并使用“去增补”。
5. 定期导出 JSON 备份。
